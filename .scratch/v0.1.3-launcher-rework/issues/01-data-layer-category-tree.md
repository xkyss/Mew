# 01 — 数据层重构:分类树模型 + 迁移 + 纯逻辑测试

**What to build:** `launcher.json` 从平铺数组重构为「分类树 + 启动项」结构:分类树是一等公民(每个分类节点有唯一 slug id、名称与子分类),启动项通过分类 id 引用归属节点(可空,表示未分类);旧格式数据首启自动迁移(旧分类文本 → 根级分类,「默认」→ 未分类);新增纯逻辑——子树聚合(选中分类返回其子树所有启动项)、「全部」= 所有分类 + 未分类、悬空分类引用(指向已删分类)加载时归一「未分类」。同时新建首个测试项目 `Mew.Launcher.Tests` 覆盖迁移 / 聚合 / 悬空归一。本票据只做数据层(expand):App 现有界面与旧模型并行存在、照常运行,不迁移 UI。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 聚合:选中分类返回子树所有启动项;「全部」= 所有分类 + 未分类
- [ ] 悬空引用:分类 id 指向不存在的分类 → 加载后归「未分类」
