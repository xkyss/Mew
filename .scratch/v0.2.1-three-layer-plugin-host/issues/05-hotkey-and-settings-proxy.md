# 05 — 热键与设置节的跨进程代理

**What to build:** 插件声明的全局热键与设置节由宿主统一承载与分发，冲突可点名，设置变更可联动。

**Blocked by:** 03 — IPC 契约与跨进程搜索聚合

**Status:** resolved

- [ ] 全局热键中央注册表仍唯一在宿主，扩展主机与独立插件声明的热键由宿主代注册，触发后经 `hotkeyTriggered` 通知归属插件
- [ ] 跨插件热键冲突集中检测，冲突时提示占用方 `label`（如“浮层呼出键”/“插件『剪贴板』快速粘贴”/“启动项『X』”），`FindOwner` 可返回占用方描述
- [ ] 插件设置节经统一注册表列入宿主设置侧边栏（与外观/热键/Launcher 数据节同列），`settings.json` 保持根节+模块节隔离（根节归宿主，模块节按插件 `id` 分）
- [ ] 宿主侧设置变更经 `settingsChanged` 推送至对应插件，插件可刷新行为
- [ ] 未声明 `hotkeys`/`settingsSection` 能力的插件其相关注册被拒绝
