# 06 — 故障隔离与可观测性

**What to build:** 扩展主机或独立插件崩溃不拖垮宿主常驻能力，崩溃可被感知并自动恢复或标为已崩溃。

**Blocked by:** 02 — 扩展主机进程与五区职责切分, 03 — IPC 契约与跨进程搜索聚合

**Status:** resolved

- [ ] 扩展主机进程退出时宿主捕获，呼出浮层、全局热键、托盘仍可用，弹 Toast 提示“扩展主机已重启”并自动拉起，布局可恢复
- [ ] 独立插件进程崩溃仅该插件在设置→插件列表中标为“已崩溃”，其搜索结果从浮层消失，不影响其他源
- [ ] `ping/pong` 超时与进程退出记入宿主日志，可用于诊断卡死与崩溃
- [ ] 协议版本不匹配的插件在列表中提示“请更新插件/宿主”且不加载其能力
