# 02 — 扩展主机进程与五区职责切分

**What to build:** 将 Workbench 五区从常驻宿主剥离至独立 JIT 扩展主机进程，宿主保持轻量常驻，五区作为首个内部插件运行，既有编译期模块零改动迁移。

**Blocked by:** 01 — 插件清单模型与发现（含校验与启用态）

**Status:** resolved

- [ ] 新增扩展主机产物（JIT）承载 Workbench 五区（活动栏、侧边栏、编辑器区、底部面板、状态栏）与主题/布局，宿主不再直接承载五区重 UI，仅保留呼出浮层空壳、托盘、全局热键、设置根节、插件发现与 IPC server
- [ ] 五区本身作为第一个内部插件与 01 的清单同路径注册，可在设置→插件列表中可见
- [ ] 既有 `IMewToolModule` 编译期模块（Launcher）零改动迁移至扩展主机，五区布局与主题行为与 v0.2.0 一致
- [ ] 扩展主机按需拉起（首次打开五区或首个 DLL 插件启用时），宿主可探活其存活态
- [ ] 扩展主机未拉起时，宿主常驻能力（浮层、热键、托盘）仍可用
