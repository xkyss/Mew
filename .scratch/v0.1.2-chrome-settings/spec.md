# v0.1.2 Native Chrome Window 与设置页规格

Status: ready-for-agent

> 版本:v0.1.2(本 spec 即该版本的 PRD,存于 issue tracker)
> 对应 ADR:`docs/adr/000102-01-native-chrome-window.md`
> 术语见 `CONTEXT.md`(标题栏、菜单栏为本次新增)

## Problem Statement

v0.1.1 使用系统标题栏,VSCode 式工作台外壳在顶部被系统标题栏割裂,外壳不完整。同时存在三处体验缺口:主题模式只能内存切换,重启即回默认;呼出浮层的全局热键硬编码 Ctrl+Alt+Space,与输入法/其他启动工具冲突时无法更换;用户无法在应用内看到主题/热键等全局设置的唯一入口,也没有查看启动项数据文件位置的地方。

## Solution

v0.1.2 为 Workbench 提供自绘标题栏的窗口壳 **NativeChromeWindow**(DWM 原生帧扩展,保留 OS 圆角/阴影/缩放/贴边,替换系统标题栏),标题栏由图标 + 菜单栏(File/Help)+ 居中标题 + 齿轮入口组成。同时新增**设置页**(编辑器区文档标签页):主题模式选择并持久化到新增的 settings.json、呼出浮层全局热键可配置、启动项数据文件路径展示。命令面板与开机自启顺延至 v0.1.3。

## User Stories

### Workbench(框架使用者视角)

1. As 框架使用者, I want Workbench 提供自绘标题栏的 NativeChromeWindow(DWM 原生帧扩展), so that 工作台外壳完整、无系统标题栏割裂感。
2. As 框架使用者, I want NativeChromeWindow 保留 OS 的圆角、阴影、拖拽缩放与贴边行为, so that 窗口观感与交互是原生水准,不需自研。
3. As 框架使用者, I want 标题栏暴露左区/居中标题/右区注入点, so that 各应用能自由放置图标、菜单栏与操作入口。
4. As 框架使用者, I want 标题栏背景跟随窗口背景、激活/非激活边框自动切换, so that 与五区主题观感一致,无需自己画 chrome。
5. As 框架使用者, I want 窗口按钮原生优先、缺失时自绘兜底, so that Win11 上保留原生 hover 与无障碍,其他环境不缺按钮。
6. As 框架使用者, I want 拖拽移动、双击最大化/还原开箱即用, so that 不用自己实现窗口壳细节。

### Launcher(终端用户视角)

7. As 用户, I want 主窗口无系统标题栏,改为自绘标题栏(图标 + 菜单栏 + 居中标题 + 设置入口), so that 界面与 VSCode 观感一致。
8. As 用户, I want 菜单栏提供 File(设置、退出)与 Help(关于), so that 常用操作有标准入口,尤其是有显式的退出途径。
9. As 用户, I want 菜单栏支持访问键与快捷键, so that 键盘流可直达菜单命令。
10. As 用户, I want 关于对话框显示应用名与版本号, so that 知道当前所用版本。
11. As 用户, I want 齿轮按钮与 File→设置 打开同一个设置页(编辑器区标签页), so that 入口统一、不打架。
12. As 用户, I want 设置页选择主题(跟随系统/亮/暗)并即时生效, so that 外观偏好可见可调。
13. As 用户, I want 主题模式在重启后保留, so that 每次打开不用重新设置。
14. As 用户, I want 状态栏的主题循环按钮与设置页的选择一致并同样持久化, so that 两处入口行为统一。
15. As 用户, I want 设置页修改呼出浮层的全局热键, so that 与输入法/其他工具冲突时可换键。
16. As 用户, I want 热键改绑后立即生效,旧热键失效、新热键可用, so that 不需要重启应用。
17. As 用户, I want 热键冲突或格式无效时有可理解的提示, so that 不会静默失败。
18. As 用户, I want 设置页展示启动项数据文件完整路径并可打开所在文件夹, so that 手写、备份、diff 都方便。
19. As 用户, I want 关闭按钮行为保持 v0.1.1 语义(隐藏到托盘常驻), so that 热键呼出等工作流不被打断。

## Implementation Decisions

- **模块划分**:两项目不变(`Mew.Workbench` 框架库 / `Mew.Launcher` 示例 App);NativeChromeWindow 属框架库,Launcher 创建并配置标题栏内容。
- **窗口方案**:照官方样例 `NativeCustomWindow`——`ExtendClientAreaTitleBarHeight`(约 28)扩展客户区进 DWM 原生标题栏区域;Win32 后端将扩展区变 HTCAPTION 提供拖拽移动;双击最大化/还原;`AlphaTextPanel` 保证扩展区文字 alpha 正确;窗口模板 + `ContentPresenter` 投影用户内容;激活/非激活边框色(`SetWindowBorderColor` 或自绘兜底)。
- **窗口按钮**:原生优先(`HasNativeChromeButtons` 为真时隐藏自绘按钮),缺失时自绘兜底(最小化/最大化/还原/关闭,含 hover/按下状态)。
- **窗口创建权**:框架提供窗口类,应用创建并注入标题栏内容;关闭→托盘隐藏、`NativeMessage`、`Loaded` 等窗口级钩子留在应用侧。
- **标题栏结构**:左区 = 应用图标 + 菜单栏;中区 = 居中标题(跟随 `Window.Title`,v0.1.2 为「Mew Launcher — v0.1.2」);右区 = 齿轮按钮(设置入口,暂不加其他入口)。
- **菜单栏**:MewUI `MenuBar`/`Menu`/`MenuItem`,File = 设置、退出;Edit 不设;Help = 关于;支持访问键与快捷键。
- **关于**:MessageBox 轻量对话框,显示应用名与版本号。
- **设置页形态**:编辑器区文档标签页(齿轮与 File→设置 指向同一文档);Workbench 提供按需打开指定文档的能力。
- **settings.json**:新增 `%APPDATA%\Mew\settings.json`,保存主题模式与呼出热键;启动项数据仍为 `launcher.json`,两文件职责分离。
- **主题持久化**:主题三选一(跟随系统/亮/暗,默认跟随系统)写 settings.json;启动时加载;状态栏循环按钮与设置页写同一处设置。
- **呼出热键配置**:从硬编码改为读 settings.json 并按配置注册(`RegisterHotKey`);设置页提供按键捕获控件,复用既有热键解析与冲突反馈(与每项热键一致);改绑后重新注册、即时生效,相关文案(如状态栏)联动显示当前热键。
- **平台**:目标 Win11,DWM 原生帧扩展;Win10 及更早自然降级为方角,不做兼容处理(ADR 000102-01)。
- **术语**:五区色板不变;标题栏是外壳 chrome,不属五区色板(`CONTEXT.md`「标题栏」「菜单栏」)。

## Testing Decisions

- **测试缝**:唯一主缝 = **Launcher App 本身**(与 v0.1.1 一致,不建独立测试项目);所有功能通过示例应用验收,从用户视角验证可观察行为。
- **验收方式**:手工冒烟清单,逐条勾验:
  1. 主窗口无系统标题栏,自绘标题栏呈现图标、菜单栏、居中标题与齿轮;标题显示 v0.1.2。
  2. 拖拽移动、双击最大化/还原、贴边缩放(OS 原生行为)正常;最大化时窗口内容不错位。
  3. 五区布局在自绘标题栏下方正常渲染;亮/暗主题切换时标题栏背景/边框/菜单/齿轮颜色即时联动。
  4. 布局持久化:窗口尺寸/位置重启后恢复,扩展客户区无干扰。
  5. 关闭按钮 → 托盘常驻;托盘菜单显示/退出正常;隐藏期间全局热键仍可用。
  6. 全局热键呼出浮层、浮层过滤/回车启动/Esc 关闭全链路不受影响;每项热键仍生效。
  7. 菜单访问键(Alt+F、Alt+H)可用;File→退出真正退出应用;Help→关于弹出版本对话框。
  8. 齿轮与 File→设置 打开同一设置页(编辑器区标签页)。
  9. 设置页主题三选一即时生效;重启后主题模式保留;状态栏循环按钮与设置页一致。
  10. 设置页可改绑呼出热键:新键立即生效、旧键失效;格式无效与冲突(如与某每项热键重复)有提示;重启后保留。
  11. 设置页展示启动项数据文件完整路径,"打开所在文件夹"可用。
  12. NativeAOT 单文件发布(win-x64、Direct2D、完整裁剪)通过,启动接近瞬时。
- **未来缝**:若 v0.1.3 引入更重的纯逻辑(如命令面板),再评估补单元测试。

## Out of Scope

- 命令面板(v0.1.3)
- 开机自启(v0.1.3;可用启动文件夹快捷方式替代)
- Win10 圆角兼容(自然降级,不修)
- 全自绘窗口路线(CustomWindow 方案,ADR 000102-01 已记取舍)
- 标题栏右区更多入口(主题快捷切换等,均收敛进设置页)
- 设置页更多项(托盘选项、外观细节、数据备份/导入等)
