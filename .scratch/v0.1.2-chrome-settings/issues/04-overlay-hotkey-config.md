# 04 — 呼出热键可配置

**What to build:** 设置页可修改呼出浮层的全局热键:按键捕获控件 → 复用热键解析校验格式 → 与每项热键冲突检测 → 按新组合键重新注册全局热键 → 持久化到 settings.json。改绑后新键立即生效、旧键失效,无需重启;状态栏等文案联动显示当前生效热键。

**Blocked by:** 03 — 设置页:编辑器区文档 + 入口 + 主题持久化

**Status:** ready-for-agent

- [ ] 格式无效与冲突(如与某启动项每项热键重复)时有可理解提示
- [ ] 改绑后持久化,重启后保留
