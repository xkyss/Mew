# v0.1.1 UI 布局示意图(ASCII)

> 辅助票据 01–12 实现时的界面共识;术语以 `CONTEXT.md` 为准,细节以 `spec.md` 为准。

## 1. Workbench 五区外壳(票据 01–03)

```
+----------------------------------------------------------------------+
|                                                                      |
|  +------+  +-------------------+  +--------------------------------+  |
|  |      |  |                   |  |                                |  |
|  |  A   |  |    Side Bar       |  |        Editor Area             |  |
|  |  c   |  |    (侧边栏)        |  |  +-------+-------+-------+    |  |
|  |  t   |  |                   |  |  | tab 1 | tab 2 | tab 3 |    |  |
|  |  i   |  |    · 分类切换      |  |  +-------+-------+-------+    |  |
|  |  v   |  |    · 工具视图      |  |                                |  |
|  |  i   |  |    · 搜索过滤      |  |   文档内容(可停靠 / 拆分)        |  |
|  |  t   |  |                   |  |                                |  |
|  |  y   |  |                   |  |                                |  |
|  |      |  |                   |  |                                |  |
|  |  B   |  +-------------------+  +--------------------------------+  |
|  |  a   |  +------------------------------------------------------+  |
|  |  r   |  |   Bottom Panel(底部面板: 日志 / 输出, 可折叠)          |  |
|  +------+  +------------------------------------------------------+  |
|  +----------------------------------------------------------------+  |
|  |   Status Bar(状态栏: 上下文信息 + 操作入口)                      |  |
|  +----------------------------------------------------------------+  |
+----------------------------------------------------------------------+
```

活动栏(最左竖条)切换侧边栏分类;编辑器区基于 MewDock tabset,支持停靠与拆分;底部面板可折叠;状态栏展示上下文信息。

## 2. Launcher 窗口内管理(票据 04–08)

```
+----------------------------------------------------------------------+
|  +------+  +-------------------+  +--------------------------------+  |
|  | 活   |  |  侧边栏(启动项列表)  |  |  编辑器区(启动项详情)          |  |
|  | 动   |  |  [搜索..............] |  |  名称     [_____________]    |  |
|  | 栏   |  |  分类: 全部/开发工具  |  |  命令     [_____________]    |  |
|  | 分   |  |  -----------------  |  |  参数     [_____________]    |  |
|  | 类   |  |  > VS Code          |  |  工作目录 [_____________]    |  |
|  |     |  |    Terminal         |  |  分类     [开发工具     v]    |  |
|  | 开  |  |    Notepad++        |  |  图标     [选择...]          |  |
|  | 发  |  |    GitHub (URL)     |  |  热键     [Ctrl+Alt+N]       |  |
|  | 工  |  |  (双击/回车启动)      |  |  [保存] [删除] [立即启动]     |  |
|  | 具  |  |                     |  |                                |  |
|  +------+  +-------------------+  +--------------------------------+  |
|  +----------------------------------------------------------------+  |
|  |  底部面板(启动日志):  14:02:31  已启动 VS Code                 |  |
|  +----------------------------------------------------------------+  |
|  +----------------------------------------------------------------+  |
|  |  状态栏: 就绪 · 最近启动: VS Code 成功 · 呼出热键 Ctrl+Alt+Space |  |
|  +----------------------------------------------------------------+  |
+----------------------------------------------------------------------+
```

活动栏 = 启动项分类;侧边栏 = 列表 + 搜索;编辑器区 = 详情表单;底部面板 = 启动日志;状态栏 = 运行状态。

## 3. 呼出浮层(票据 09–10)

```
+----------------------------------+
|  [ 输入过滤...                 ]  |
+----------------------------------+
|  > VS Code               Ctrl+Alt+N |
|    Terminal                        |
|    Notepad++                       |
|    GitHub (URL)                    |
+----------------------------------+
|  5 项 · 上下选择 · Enter 启动 · Esc 关闭 |
+----------------------------------+
```

任意窗口之上按 `Ctrl+Alt+Space` 呼出;复用侧边栏同一过滤逻辑与同一份启动项数据;行尾显示每项热键。

## 4. 数据流(票据 04、09–11)

```
                 +------------------------------+
                 |  启动项数据(单一 JSON)         |
                 |  %APPDATA%\Mew\launcher.json  |
                 +--------------+---------------+
                                | 加载 / 变更自动保存
          +---------------------+---------------------+
          v                     v                     v
+-----------------+   +-----------------+   +-----------------+
|  窗口内管理视图   |   |  呼出浮层        |   |  每项热键        |
|  (票据 04–08)   |   |  (票据 09)       |   |  (票据 10)       |
+-----------------+   +-----------------+   +-----------------+
```

窗口、浮层、每项热键共用同一份数据,任意一处修改即时生效。
