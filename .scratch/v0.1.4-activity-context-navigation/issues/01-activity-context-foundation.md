# 01 — 活动栏上下文的基础导航

**What to build:** 让 Launcher 的“启动”和“设置”使用 Workbench 原生的活动栏上下文导航：每个活动栏项唯一对应一个侧边栏视图；点击非当前项切换并显示对应视图；侧边栏显示时重复点击当前项收起，收起后再次点击恢复；当前活动栏项持续显示为选中状态。活动栏不再承载独立动作。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 活动栏项和侧边栏视图以一对一关系注册，非法或含糊的配对无法形成活动栏上下文。
- [ ] Launcher 可在“启动”和“设置”间切换，且重复选择、收起与恢复的可见行为符合规格。
- [ ] 切换或收起侧边栏不会改变编辑器区当前文档。
- [ ] 当前活动栏项具有持续选中样式，收起侧边栏后仍保持。
