# 03 — 在侧边栏定位当前文档

**What to build:** 让具有活动栏上下文归属的编辑器文档在标签右键菜单提供“在侧边栏定位”。执行后切换到文档所属活动栏上下文、展开侧边栏并选中对象；普通的编辑器标签切换和关闭保持不自动反向导航。应用可额外注册该命令的快捷键，无归属文档不提供命令。

**Blocked by:** 01 — 活动栏上下文的基础导航.

**Status:** ready-for-agent

- [ ] 有归属文档的标签右键菜单可发现“在侧边栏定位”，执行后展示完整的对应导航位置。
- [ ] 无归属文档不显示或不可用该命令，且不会制造虚假的侧边栏选择。
- [ ] 编辑器标签的激活与关闭不自动切换活动栏、展开侧边栏或改写侧边栏选择。
- [ ] Launcher 能按应用需要为定位命令注册快捷键。
