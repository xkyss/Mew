# 03: 扩展主机切换共享面板（IPC adapter + 2s 读超时）

**What to build:** 扩展主机设置→插件的行区块换用共享插件管理面板：adapter 包发现结果 + 本地只读启用缓存 + DLL 装载实载集合，写走一次性 IPC 并加 2s 读超时；本地缓存角色钉死（启动读盘供装载跳过禁用项、ack 成功后内存同步、永不本地落盘）。行序由发现顺序变 id 排序（唯一确认豁免），其余零回归；宿主挂起不再冻结扩展主界面。

**Blocked by:** 01, 02

**Status:** resolved

- [x] 扩展主机面板行由共享面板渲染，行为与 v0.2.3 一致（含「重启扩展主机后生效」副提示）
- [x] 行序由发现顺序变为 id 排序（唯一确认豁免），其余零回归
- [x] 开关三结果语义保持：宿主确认→内存同步+刷新；宿主拒绝→「宿主未生效」提示；不可达→提示且不改本地状态
- [x] 读路径 2s 超时（与连接超时对称），超时按不可达处理，UI 不再可能被无界读阻塞
