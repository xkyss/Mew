# 03: 插件分工与置灰

**What to build:** 宿主侧只接受独立进程插件，运行期 DLL 置灰并提示需扩展主机；扩展主机侧只组装编译期工具模块与运行期 DLL，单项失败不影响其他项；清单字段与契约版本不变，越权注册照旧拒绝。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 宿主侧可加载集合不含运行期 DLL，其健康态为需扩展主机并给出提示
- [ ] 扩展主机侧按名单隔离加载运行期 DLL，模块标识与清单标识不一致或文件缺失时单项失败且不影响其他项
- [ ] 编译期工具模块零改动继续在扩展主机中运行
- [ ] 清单字段、版本规则、契约版本不分叉；未声明能力的注册被拒绝，版本不匹配被拒绝并提示更新
- [ ] 行为测试覆盖宿主侧过滤置灰、扩展主机侧加载成败隔离、越权与版本拒绝
