# 02: 插件页目录节替换与布局优化

**What to build:** 插件设置页的目录区替换为单行主目录形态：当前路径展示 + 「修改」按钮（MewUI 自带文件夹选择器）+ 反馈（初始隐藏,选择/校验失败才现）+ 精简说明（修改后重启宿主生效；开发期建链两条路径——`mklink /D` 需开发者模式可指 WSL、`mklink /J` 免特权限本机卷）；「设为默认/删除/添加/锁定行/优先级文案」全部退役。整页以滚动容器包裹,超高内容可滚；目录反馈空态不占位。用户可见行为：打开设置→插件看到一行主目录与修改入口,修改走选择器并按提示重启宿主后生效。

**Blocked by:** 01

- [ ] 「设为默认/删除/添加/锁定行/优先级文案」退役,`EditablePluginDirs`/`SavePluginDirs` 列表机制移除
