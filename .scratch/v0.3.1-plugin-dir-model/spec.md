# v0.3.1 插件目录模型规格

Status: ready-for-agent

> 版本: v0.3.1
> 对应 ADR: `docs/adr/000301-01-plugin-dir-model.md`（修订 ADR-000203 卸载语义注记）

## Problem Statement

多目录插件模型（`settings.pluginDirs` 列表 + 目录管理 UI + `MEW_PLUGINS_EXTRA` + 安装目录根）为「主目录可替换」的假想灵活性持续买单：目录节是插件设置页最复杂的一块，但真实证据显示第一项永远是用户目录本身（且为空）、env 从未配置、唯一的第三方插件靠第二项目录指向构建输出；「第一项为默认」与「env 永远最前」的文案自相矛盾。用户的开发工作流——构建输出不复制、直接联调——应由文件系统原生的链接承担，而非一套目录列表机制。0.20 重做插件页在即，正是收敛时机。

## Solution

**单一主插件目录**（默认 `%APPDATA%\Mew\Plugins`，可通过自带文件夹选择器修改，重启宿主生效）承载全部插件：主目录下的子目录即插件；**开发期把构建输出以链接（junction/symlink）挂进主目录**——现有发现机制对链接目录原生可用，零发现代码改动，以测试锁定。多目录列表、优先级语义、`MEW_PLUGINS_EXTRA`、安装目录扫描根全部移除；settings 做一次性单值化迁移。

## User Stories

1. As 用户, I want 一个主插件目录（默认用户目录,可修改）承载全部插件, so that 插件放哪、怎么卸载一目了然。
2. As 用户, I want 用文件夹选择器修改主目录并按提示重启宿主, so that 改目录不需要手编 settings.json。
3. As 开发者, I want 把插件构建输出以链接挂进主目录, so that 开发期免复制直接联调,构建即生效。
4. As 开发者, I want 链接扫描行为有测试锁定, so that 升级 MewUI/重构发现逻辑时链接通道不碎。
5. As 用户, I want 插件设置页的目录区只剩一行主目录与修改入口, so that 页面不再被「设为默认/至少保留一项/优先级」的说明占满。
6. As 用户, I want 删除主目录下的插件子目录即完成卸载, so that 卸载是文件系统原生动作、无按钮无词汇负担。
7. As 框架主人, I want 配置源唯一(settings 单值 pluginDir), so that 不再有 env/列表/安装目录多套机制的心智与代码负担。
8. As 框架主人, I want 旧 pluginDirs 列表一次性迁移且被移除的目录有日志提示, so that 升级不静默丢失任何在用的目录。
9. As 框架主人, I want 迁移代码不做文件系统特权操作(不自动建链接), so that 升级行为可预测、无环境依赖。
10. As 用户, I want 插件设置页超高内容可滚动, so that 目录与插件行多时不被窗口高度截断。
11. As 用户, I want 目录反馈与插件行通知的显示位置合理且空态不占位, so that 页面无空洞无歧义。
12. As 开发者, I want 单根发现的优先级语义简单明确(主目录内按子目录名序,重复 id 先到者为准、后者标红), so that 冲突行为可预测可测。
13. As 文档读者, I want ADR-000203 的卸载语义注记同步修订, so that 「删子目录即卸载」与「卸载专指 uninstall」的边界不失传。
14. As 框架主人, I want Windows 侧 AOT 发布与走查(含文件夹选择器、链接联调、迁移)作为验收门槛, so that 本机测试绿不免除运行验证。

## Implementation Decisions

- **发现模型单值化**：扫描根收敛为唯一主目录；`ResolvePluginRoots`、`GetExtraPluginDirs`、安装目录根退役；宿主与扩展主机两处发现接线同步收敛；宿主写快照的职责与流程不变（ADR-000202）。
- **settings 迁移**：`pluginDirs` 列表 → 单值 `pluginDir`（取列表首项，缺省用户目录；其余条目不进新模型、由宿主日志提示人工建链接）；迁移沿用既有一次性迁移先例，损坏/缺失回退默认。
- **链接支持**：发现代码零改动（实测 junction/symlink 枚举与穿透可用）；仅以测试锁定行为，并在目录节说明文案写明两条建链路径（`mklink /D` 需开发者模式可指 WSL/UNC，`mklink /J` 免特权限本机卷）。
- **目录节 UI 替换**：当前主目录路径展示 + 「修改」按钮（文件夹选择器）+ 反馈（初始隐藏）+ 精简说明（重启生效 + 建链路径）；「设为默认/删除/添加/锁定行/优先级文案」全部退役。
- **插件页布局**：整页滚动容器包裹；目录反馈初始不占位；`MEW_PLUGINS_EXTRA`、`ResolvePluginRoots` 相关文档措辞同步清理。
- **主目录修改后生效**：提示重启宿主；「重扫 IPC」不进本版（独立票）。

## Testing Decisions

- **好测试的标准**：只测外部行为——单根发现结果、链接子目录被枚举且可读、迁移往返、重复 id 优先级；不测对话框内部与像素。
- **单一高位缝**：宿主测试工程（沿用纪律）。① 单根发现 + **链接子目录**（无头 symlink,仓库运行环境原生支持）覆盖：真实目录、链接目录、重复 id 先到优先；② settings 迁移往返（列表→单值、缺省回退、损坏回退）；③ 既有全量回归（141 + 103）。
- **先前技艺**：`PluginDiscoveryTests`（发现纯逻辑）、settings 迁移用例（`MigrateLegacySettingsDocumentLayout` 先例）、组合测试的无头控件树。
- **运行期项进 Windows 走查**：文件夹选择器、主目录修改后重启生效、真实 junction/symlink 联调（symlink 建链需开发者模式,本机无头测试用 Linux symlink 等价锁定枚举语义）。

## Out of Scope

- **不做重扫 IPC**：主目录修改后仍按提示重启宿主生效；运行期重扫/即时生效另票。
- **不做卸载按钮/插件安装器**：删子目录即卸载（ADR-000301 语义）；安装仍是「放进主目录」。
- **不动插件行管理**（v0.2.4 插件管理面板）、不动 ADR-000201/202 的三层结构与发现-快照分工。
- **不做「装载失败」健康态覆盖**（昨天评审的 P1,独立票）。
