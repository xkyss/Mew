## 0. 准备

- [ ] AOT 发布双 exe:`dotnet publish src/Mew.Host -c Release -r win-x64 /p:PublishAot=true -o publish` + `dotnet publish src/Mew.PluginHost -c Release -r win-x64 -o publish`,产物可启动(v0.3.0 硬门槛)
