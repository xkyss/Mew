# 05: 宿主侧 T3 管理 UI

**What to build:** 宿主窗口/托盘长出 T3 独立插件的管理入口：列出 exe 插件行（状态词与动作由 01 推导），提供启用/禁用开关与重启动作（接线到 04 的进程托管）；已崩溃行动作变「重启」；不依赖扩展主机活着即可管理 T3。宿主自身开关直接落盘 `plugins.json`（宿主本就是唯一写者，与 03 的写权力归一自洽）。

**Blocked by:** 01, 04

**Status:** ready-for-agent

- [ ] 禁用 T3 → 立即杀进程且来源消失；重启 → 宿主重新拉起该进程
- [ ] 扩展主机未运行时 T3 行仍可见可管
