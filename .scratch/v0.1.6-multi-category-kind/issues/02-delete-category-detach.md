# 02 — 删除分类 = 摘除归属(永不删项)

**What to build:** 删除分类的语义从「连根删(连带删除启动项)」改为「摘除归属,永不删项」:从所有引用它的启动项上摘掉该分类,子分类随父分类整棵子树一并摘除;项还有其他归属则保留,一个归属都不剩则归「未分类」。删除确认框与删除后的界面刷新同步更新。

**Blocked by:** 01 — 多分类数据模型与迁移

**Status:** resolved

- [x] 删除一个分类后,其下启动项不被删除
- [x] 被删分类下、同时属于其他分类的启动项,仍在其所属分类下可见
- [x] 被删分类下、一个归属都不剩的启动项,归入「未分类」
- [x] 删除父分类时,子分类整棵子树一并摘除归属
- [x] 删除确认框提示「N 个启动项将失去分类 X」,不再提示「删除 N 个启动项」
- [x] 删除后侧边栏树、列表、详情刷新正确;详情正显示被删分类的项时,界面回退到「全部」或清空

**Comments**

- 实现:新增 `LauncherData.DetachCategoryIds`(纯函数,从每个启动项摘掉给定 id 集合,永不删项);`LauncherApp.DeleteCategory` 改用该函数 + 确认文案改为「N 个启动项将失去此分类」;`_items` 由 `readonly` 改为可重赋值以支持换树后保存。
- 删除后当前导航若落在被删分类(或其子孙),回退到「全部」;详情若正显示被删分类的项则清空。
- 测试:LauncherDataTests 新增 3 例(保留其他归属 / 一个不剩归未分类且永不删项 / 子树 id 集合一并摘除),连同 LauncherDataTests + LauncherStoreTests 共 35 例通过。
