# 启动上下文交互模型：列表即启动面，编辑退居二线

主窗口启动项列表（卡片/列表两形态）以「单击=启动」为唯一主手势，双击忽略（防重，避免单击启动后双击连开两次），行尾常驻「启动」按钮移除，编辑入口退居右键菜单与悬停「编辑」按钮；详情文档保留为编辑面，其标签动态显示当前项名。这样与呼出浮层（单击即启动）手势一致，避免同一语义的启动项在两种界面里手势分裂。

## Considered Options

- **单击开详情、双击启动（原状）**：编辑导航直观，但双击难发现且先触发单击（详情弹开）再启动，两条启动路径并存。
- **单击启动（选定）**：与浮层及主流启动器习惯一致，主操作最直接；编辑经右键/悬停按钮，低频操作不抢主路径。

## Consequences

- 列表不再承担「单击开详情」的编辑导航，详情文档仅由右键「编辑」与悬停「编辑」按钮打开。
- v0.1.4 的「侧边栏对象单击开详情」保持不变：侧边栏是导航面，列表是启动面，两处语义不同属有意区分。
- 列表引入选中概念（键盘导航），选中态（accent）与悬停态（微亮）视觉分离。
- 详情页表单内不再显示名称/id 标题，对象身份由动态标签与「名称」字段承载。
