# 活动栏上下文驱动的三栏导航

Workbench 将活动栏、侧边栏与编辑器区划分为明确的单向导航关系：每个活动栏项唯一对应一个侧边栏视图，活动栏只承担导航；侧边栏中的可编辑对象打开或激活其唯一的编辑器文档；编辑器区切换或关闭标签不自动反向改变活动栏上下文。这样保留编辑器区的独立工作流，并避免用户切换标签时意外丢失分类、筛选或侧边栏状态。

## Considered Options

- **编辑器区自动反向同步**：每次激活文档都切换活动栏并在侧边栏定位对象；导航关系直观，但会在普通标签切换中打断用户正在浏览的侧边栏上下文。
- **活动栏承载任意动作**：复用图标栏放置刷新、主题切换等操作；入口集中，但使当前项、收起/恢复和布局恢复失去确定语义。
- **活动栏上下文驱动的单向导航（选定）**：活动栏与侧边栏一对一，侧边栏到编辑器区单向打开/激活，反向定位由用户显式请求。

## Consequences

- 重复选择当前活动栏项会收起侧边栏，收起不清除活动栏上下文；再次选择会恢复对应视图。工作台恢复当前项和侧边栏显隐，失效项回退到第一个已注册项。
- 编辑器标签右键提供“在侧边栏定位”，应用可额外绑定快捷键；该命令展开侧边栏、切换到文档所属的活动栏上下文并选中对象。无所属活动栏上下文的文档不提供该命令。
- 侧边栏筛选在同次运行的上下文切换间保留，工作台重启后不恢复。
